# 🚦 Proyecto: Semáforo Inteligente

## 📋 Presentación del Proyecto
Este proyecto consiste en el diseño, desarrollo e implementación de un **sistema de semáforo controlado por microcontrolador**. El objetivo principal es simular el funcionamiento real de un semáforo de tránsito mediante luces LED y un temporizador programado, garantizando una secuencia de señalización clara y continua (Rojo, Amarillo, Verde).

Este sistema sirve como base para proyectos de automatización, control de tráfico vehicular y prácticas de electrónica básica y programación.

## 🧰 Herramientas Empleadas

### Software y Entornos
* **Arduino IDE:** Para la escritura, compilación y carga del código al microcontrolador.
* **Tinkercad / Fritzing:** Para la simulación previa y diseño del esquema electrónico.
* **Mermaid:** Para la generación del diagrama de flujo integrado en Markdown.
* **Canva:** Para la creación de la presentación visual del proyecto.

### Hardware / Herramientas Físicas
* Cable USB tipo A a B (para conexión de la placa al PC).
* Multímetro digital (opcional, para medición de voltajes y continuidad).
